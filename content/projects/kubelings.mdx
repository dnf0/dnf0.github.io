**Kubelings** is a client-side WebAssembly interactive learning platform and comprehensive reference manual for mastering Kubernetes from the ground up. Inspired by the pedagogical philosophy of [Rustlings](https://github.com/rust-lang/rustlings) and [Ziglings](https://codeberg.org/ziglings/exercises), Kubelings guides engineers through fixing broken declarative YAML manifests, constructing multi-container sidecars, writing RBAC authorization rules, configuring Gateway API routes, orchestrating distributed AI workloads with KubeRay, and troubleshooting cluster incidents.

### Pedagogical Philosophy

Learning Kubernetes from static documentation or copy-pasted Helm charts is difficult because feedback loops are slow and failure messages are cryptic. Kubelings solves this through guided, test-driven micro-learning:

1. **Active Debugging & Iteration**: Every exercise starts in a broken or incomplete state with clear `# TODO:` prompts. You inspect the failure and edit the code until it passes schema and behavioral verification.
2. **Instant WebAssembly Feedback Loop**: Manifest changes are evaluated in `< 1ms` inside a background Web Worker running Python 3.12 and PyYAML via WebAssembly.
3. **Zero Installation**: Practice anywhere with zero prerequisite tools—no Docker daemon, no minikube, and no cloud accounts needed.
4. **Progressive Hints & Solutions**: Multi-tiered conceptual hints guide your mental model before revealing concrete YAML syntax solutions.

### Core Features & Architecture

- **⚡ Zero-Install Wasm IDE**: Complete 114-exercise WebAssembly curriculum powered by Pyodide, Monaco Editor, side-by-side solution diffing, progressive hinting, and `localStorage` progress tracking with JSON backup import/export.
- **🔗 Deep Linking & Instant Sharing**: Full URL query-param routing (`?exercise=<id>` and `?chapter=<num>`) with live browser history synchronization.
- **📚 26 Architectural Reference Guides**: In-depth documentation covering Kubernetes internals, annotated manifest anatomies, production hardening advice, and troubleshooting triage trees.
- **VS Code Extension**: Dedicated Activity Bar curriculum explorer, status bar progress, on-save schema diagnostics, and side-by-side reference solution diffing.

### Curriculum Matrix (26 Chapters · 114 Exercises)

- **01–06 Workloads, Config & Storage**: Pods, multi-container sidecars, Deployments, StatefulSets, ConfigMaps, Secrets, PV/PVC storage, ClusterIP/NodePort/LoadBalancer services, Ingress controllers.
- **07–10 Scheduling & Reliability**: Node affinity, taints/tolerations, topology spread, RBAC authorization, NetworkPolicies, liveness/readiness/startup probes.
- **11–18 Advanced Kubernetes**: HPA v2 autoscaling, Custom Resource Definitions (CRDs) & Python operators, incident troubleshooting, GitOps/ArgoCD, Cilium eBPF, Kyverno/Gatekeeper policy-as-code, multi-tenancy vcluster, mutating/validating webhooks.
- **19–26 Modern Cloud-Native & AI Infrastructure**: Helm v3, Kustomize overlays, Gateway API, Crossplane infrastructure-as-data, Tetragon eBPF security, KubeRay distributed clusters, Kueue/Volcano batch scheduling, and GPU Dynamic Resource Allocation (DRA).
